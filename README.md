# Red Team vs Blue Team Attack & Defense Simulation

## CDAC PGCP-ITISS Final Project

### Overview
This project demonstrates a realistic enterprise cybersecurity environment where Red Team activities are simulated and Blue Team monitoring, detection, and incident response are performed in a controlled lab.

### Objectives
- Simulate the cyber attack lifecycle.
- Monitor and detect attacker activities.
- Investigate security incidents.
- Map attack techniques to the MITRE ATT&CK framework.
- Improve defensive strategies through analysis.

### Technologies
- Kali Linux
- Windows
- VMware Workstation
- Wazuh
- Sysmon
- Wireshark
- Metasploit
- Nmap
- MITRE ATT&CK
